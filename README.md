# 착한구두 팀별 주간보고

탭은 **콘텐츠기획 → 마케팅 → 해외시딩** 순서입니다.

- 콘텐츠기획: 크리에이터 시딩 진행·성과, 메타 PA 광고, 매장광고 별도 집계.
- 마케팅: 메타광고를 먼저, 같은 시딩 지표를 뒤에 표시합니다.
- 해외시딩: 서울링크 원본의 단계별 현황, 국가별 조회수, 업로드 인사이트.

원본 레이아웃: https://seoul-link.github.io/weekly-report-91i90h1e/brands/mplayground-gwangjang.html

## 데이터

- 콘텐츠기획은 사용자가 지정한 EDIT 운영 페이지의 `data.json`과 표시된 콘텐츠·PA 광고 성과를 읽습니다. 다른 팀의 게시물을 합치지 않습니다.
- 마케팅은 `chaakan-creator-hub`의 브랜더진·크리에이터 게시물과 메타 파트너콘텐츠 광고를 인증된 읽기 API로 연동합니다. 게시물 링크는 중복을 제거하고, 관리시트에 같은 사람으로 등록된 여러 계정은 인원에서 한 번만 셉니다. 광고는 원본처럼 같은 광고명을 합산하고 `stale` 기록은 제외합니다.
- 마케팅 비용은 원본 정의를 따릅니다. 브랜더진은 협업비+확인된 2차 활용비, 크리에이터는 관리시트 귀속 월의 건당 단가입니다. 제품원가·광고별 비용 배분은 원본에 없으므로 광고비 ROAS와 구분하며 총비용 ROAS를 만들지 않습니다. 15일 측정치를 14일로 바꾸지 않습니다.
- 해외시딩은 구글 시트 `해외시딩` 탭(한 줄 = 게시물 1건, 1행 머리글 A~T 입력·U~Y 자동 계산)을 읽기 전용 Sheets API로 읽어 집계합니다. 필수 칸(담당자·ID·국가·채널·진행 단계·유·무상)이 비거나 무상인데 원고료가 있으면 행 번호와 함께 읽기를 멈추고 마지막 정상 데이터를 유지합니다. 같은 ID의 두 번째 게시물은 `ID_2`로 구분하되 인원은 한 번만 셉니다. 국가 구분: 샤오홍슈 채널 → 샤오홍슈, 대만·홍콩 → 대만·홍콩, 일본·한국, 그 외 기타. 목표 조회수는 `작성안내` 탭 A14:B18 표에서 읽습니다. 시트 ID·인증 파일 경로는 `local-config.json`(git 제외)에만 둡니다. 샤오홍슈는 평균 조회수 = 평균 좋아요×75, 조회수가 비어 있으면 좋아요×75로 추정하고 페이지에 '추정'으로 표시합니다. 예상 공유·저장은 시트에서 받지 않으므로 '—'로 표시합니다.
- 원본 스프레드시트·인사이트 증빙·비고·인증정보는 공개 저장소에 업로드하지 않습니다. 입력 파일은 PC에 보관하고 필요한 보고 필드만 배포합니다.
- 오류가 발생하면 마지막 정상 데이터를 유지합니다. 중복 관리번호에 다른 값이 있으면 자동으로 합치지 않습니다.

## 자동 갱신

`tools/sync.py`가 `local-config.json`에 지정된 팀별 엑셀과 제출 폴더를 읽고 `docs/data.json`을 갱신합니다. Windows 예약작업은 2분 간격으로 실행합니다. 해당 PC가 켜져 있어야 하며, GitHub Pages의 배포 시간이 추가될 수 있습니다.

웹페이지는 1분마다 배포된 자료를 확인합니다. 원본 데이터의 수집 시각과 보고서 반영 시각은 다를 수 있으며 둘 다 표시합니다.

마케팅 원본은 15분 캐시 후 재수집하며 기존 2분 예약작업이 갱신·배포합니다. 회사 계정의 Firebase 인증은 `runtime/marketing-auth.json`, 원본은 `runtime/marketing-source.json`에만 보관하며 둘 다 git 제외입니다. 인증 만료·수집 실패 시 마지막 정상 데이터와 갱신 실패 안내를 유지합니다. 최초 인증 또는 재인증은 사용자의 명시적인 브라우저 창 허용 후 `python tools/marketing_login.py --allow-browser`로 별도 임시 창에서 진행합니다. 기존 Chrome 프로필이나 창을 사용하지 않습니다.

## 계산 기준

- 해외시딩 결과는 업로드 +7일 이후, 보고 기준일 안에 실제 측정한 값만 포함합니다. 비용 지표는 유상 게시물만 대상으로 합니다.
- 국내 시딩은 최근 측정 / 48시간 / 7일 / 14일을 선택합니다. 원본에서 해당 구간을 수집하지 않았다면 비워 둡니다.
- 공유·저장은 둘 다 확인된 경우에만 합산합니다. 실제 0과 미확인을 구분합니다.
- 공유·저장 단가는 같은 표본의 비용 합 ÷ 공유·저장 합입니다. 개별 단가의 평균이 아닙니다.
- 국내 콘텐츠 비용은 원고료 + 제품원가입니다. 배분이 확인되지 않은 합산 계약을 임의로 나누지 않습니다.
- 메타광고 귀속매출과 시딩 귀속매출은 서로 더하지 않습니다. 오프라인 매장광고도 별도 표로 구분합니다.
- 같은 크리에이터의 여러 계약은 행을 유지하되 전체 인원에서는 중복을 제거합니다. 단계별 인원은 미완료된 가장 이른 단계에 배치합니다.

검증: `python tests/check.py` — 별도 headless Chromium으로 탭 순서·펼침·모바일 폭·집계 수식을 검증합니다. 사용자 브라우저 프로필을 사용하지 않습니다.

마케팅 원본 대조: `python tests/marketing_check.py` — 비공개 수집 캐시로 비용·광고 합계, 게시물 중복, 월별 단가, 수집 실패 보존, 엑셀 중복 차단, 공개 필드 제한을 확인합니다.
